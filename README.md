# City Weather App

This is a simple weather app I built using HTML, CSS and JavaScript.

I created this project to practice JavaScript, especially working with APIs and asynchronous programming.

## Features

- Search weather by city name
- Shows temperature
- Shows weather condition
- Shows humidity
- Shows wind speed
- Responsive design
- Handles invalid city names

## Technologies Used

- HTML
- CSS
- JavaScript
- Fetch API
- OpenWeatherMap API

## What I Learned

While building this project, I learned about:

- Promises
- async/await
- Fetch API
- API requests and responses
- JSON
- Error handling
- DOM manipulation
